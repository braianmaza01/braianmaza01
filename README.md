## 👋 Sobre mí

Soy **desarrollador fullstack** de La Rioja, Argentina. Construyo aplicaciones web completas — desde la interfaz hasta la base de datos — con foco en productos reales para negocios reales: e-commerce, sistemas de gestión y SaaS.

- 🚀 Actualmente convirtiendo mi sistema de gestión gastronómica en un **producto SaaS multi-tenant**
- 💼 Trabajo freelance con clientes de e-commerce y gestión comercial
- 🎓 Formación intensiva fullstack JavaScript en Gestar Grupo Educativo
- 📫 Abierto a oportunidades laborales y proyectos freelance

## 💼 Proyectos destacados

### 🛒 URBX — Plataforma E-commerce
Tienda online completa con catálogo filtrable, carrito, checkout como invitado, pagos con **Mercado Pago Checkout Pro** (con webhook), notificaciones de pedidos por WhatsApp, panel de administración animado con CRUD, gestión masiva de pedidos y dashboard de ventas mes a mes.

`React` `Vite` `Tailwind` `Node.js` `MongoDB` `Mercado Pago`

🔗 **[Ver demo](https://urbx-store.netlify.app/)** 

---

### 🍽️ Sistema de Gestión Gastronómica
Sistema integral para bares y restaurantes: autenticación JWT con roles, CRUD de menú, gestión de pedidos con delivery, control de gastos y cierres de caja con reportes de ganancia neta. En evolución hacia un **SaaS multi-tenant**.

`Node.js` `Express` `MongoDB` `JWT`

🔗 **[Ver repositorio](https://github.com/braianmaza01/restaurante-menu-crud)** <!-- ← ajustar al repo definitivo -->

---

### 🏋️ FitManager — SaaS para Gimnasios
Sistema de gestión de gimnasios con notificaciones automáticas por **WhatsApp** para vencimientos y recordatorios.

`Node.js` `Express` `MongoDB` `WhatsApp API`

🔗 **[Ver demo](https://fitmanager-gym.netlify.app/login)** 

---

### 🌐 Portfolio Personal
Sitio personal con animaciones, sección de habilidades y showcase de proyectos.

`React` `Vite` `Tailwind` `Framer Motion`
